# 黄果 PotPlayer 点播台

把网页目录、搜索和剧集解析转换为适合 PotPlayer 使用的本地点播界面。程序不包含视频文件，也不会修改 PotPlayer 设置。

## 使用方法

1. 解压整个压缩包，不要只把 EXE 单独拖出来。
2. 双击 `启动点播台.cmd`。程序会在后台启动、显示系统托盘图标并打开默认浏览器。
3. 选择分类、收藏、观看记录或搜索片名：
   - 点击某一集：先验证 HLS 清单与首个媒体片段，再调用 PotPlayer；
   - 点击“整剧加入 PotPlayer”：后台逐集验证，可查看进度或取消；失败单集会被跳过；
   - 点击“复制已生成 M3U”：复制当前整剧任务生成的 M3U 下载地址；首次使用前需先完成一次整剧任务。
4. 可从托盘菜单打开页面、重启服务或退出，也可以运行 `停止点播台.cmd`。

## 稳定性与点播方式

- 内容源、封面和视频清单遇到连接中断、超时、限流或临时 5xx 时，会自动重试 3 次（350 ms、800 ms、1600 ms）。
- 单集播放会预检主清单、子清单与首个媒体片段；地址失效时会重新解析一次。
- 整剧任务同时最多验证 2 集，并显示完成数、成功数和失败数；取消会中止正在进行的网络请求。
- 整剧任务会在打开 PotPlayer 前逐集解析并验证，只把成功剧集写入直链 M3U；播放列表不包含本地令牌或已确认不兼容的本地 `/vod` 中转地址。
- 视频源直链可能由上游设置有效期。旧列表失效时，回到点播台重新执行“整剧加入 PotPlayer”即可刷新。
- 目录、搜索、详情和播放页都带结构检查；内容源改版时会显示持久警告并写入诊断信息。

## 收藏、记录与本机数据

- 收藏和观看记录保存在 `%LOCALAPPDATA%\HuangguoPotPlayer\library.json`。
- “继续点播”记录的是上次成功交给 PotPlayer 的剧集，不读取或修改 PotPlayer 内部播放进度。
- 设置保存在 `%LOCALAPPDATA%\HuangguoPotPlayer\settings.json`。
- 本地 M3U 保存在 `%LOCALAPPDATA%\HuangguoPotPlayer\playlists`，超过 7 天会自动清理。
- 首次启动会迁移程序目录旁原有的 `settings.json` 和播放列表；原文件会保留。

## 诊断与安全

- 网页右上角“◎”可查看并复制最近重试、播放验证、整剧任务和内容源结构状态。
- 诊断信息不会包含会话令牌或视频地址。
- 服务只监听 `127.0.0.1`，严格校验 Host、Origin 和随机会话令牌，拒绝跨站操作与 DNS 重绑定入口。
- 复制出来的 M3U **下载地址**带本次服务会话令牌，服务重启后需重新复制；已写入本机并加入 PotPlayer 的直链列表不依赖本地服务令牌。
- 请只播放你有权访问的内容，并遵守内容来源的使用条款与当地法律。

## 常见问题

**浏览器显示内容源连接失败**

程序会先自动重试 3 次。仍失败时，请确认网络可以直接打开 `https://huangguoai.com/`，或打开“运行诊断”查看失败阶段。

**PotPlayer 显示服务器关闭或地址错误**

先回到网页重新点击单集，或重新执行“整剧加入 PotPlayer”刷新视频源直链；不要继续使用旧版本生成的 `127.0.0.1/vod/...` 列表。

**点击剧集后没有打开 PotPlayer**

进入网页右上角“设置”，填写 PotPlayer 的完整 EXE 路径并保存。

**Windows 提示未知发布者**

这是本地生成、未购买代码签名证书的便携程序。压缩包附带 `source` 目录，可审阅全部源代码。

## 系统要求

- Windows 10/11 x64
- 已安装 PotPlayer 64 位或 32 位版本
- Windows PowerShell 5.1（用于系统托盘菜单）
- 能访问目标站点和其视频 CDN
